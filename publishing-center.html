回官網前往 ERP 貼文中心
16項完整圖文檢查工具已啟用；自動品牌守門目前維持提示模式。系統尚未全部驗收前，不因自動文字／圖片判定直接鎖住你的審核操作；品牌、產品、規格、價格／活動、季節、天氣、場合、地點、情境、環境、冷熱、表情、動作、小老闆與夥伴、比例尺寸、重複圖仍會逐項提示。正式產品主檔維持六項規格鎖定，不接受未確認規格。
產品圖片權威已切到 products-v3 正式原圖。發佈中心會把舊 products-v2、舊DM或錯誤產品主圖校正回 products-v3 使用者確認的正式產品原圖；所有產品只允許整體等比例顯示，禁止拉寬、拉高、裁切、AI重畫或把不同產品強制做成同高／同寬。小老闆仍依文案使用網站正式Q版情境素材。
第一批5篇產品／多產品候選已完成並進待審核。「六項產品總覽、龜鹿膏與龜鹿飲搭配、怎麼選、使用方式、依習慣選擇」已改用 products-v3 正式原圖的獨立產品卡構圖；不宣稱卡片間是實物相對大小，不把不同包裝硬排等高／等寬，仍須完成16項人工審核。
5篇小老闆日常找到精準官網核准圖，已直接回待審核。招手歡迎、指向看板、端溫水、看鍋燉煮、思考問題各使用一張 approved-v405 官網專用完整原圖；不裁切、不混用LINE OA素材，也不把同一張圖重複套給多篇。
嚴格預檢不合格舊圖會隔離，不硬塞上線。生活／天氣／料理類若不需要產品，可用純情境圖；涉及產品的使用／選擇／規格內容，只能嵌正式產品原圖。文案、季節、環境、冷熱、表情、動作或產品規格不合，就用「圖不符合｜ChatGPT生成」建立新候選，再回待審核。
目前已知115篇角色候選仍需重生成。v13節慶／地點／萬華72篇、v14剩餘小老闆日常27篇、v15陪伴角色16篇；舊圖曾裁切LINE OA角色或使用未核准向量陪伴角色，現在維持 needs_generation。其他「有候選圖」也不代表已核准，仍須完成16項人工審核。
正式發布責任已分開。公開 GitHub Pages 只負責正式母本、候選圖、16項審核與交接，不保存 Facebook／Instagram／LINE 等平台 Token，也不會把本機紀錄假裝成平台發布成功。公開頁完成審核後按「匯入ERP草稿｜再審核發布」，ERP 固定建立草稿，正式人工審核後可自行選擇固定排程或真正的「立即發布」。needs_generation 貼文交接時不帶任何舊圖／舊SVG，只帶文案草稿。
龜鹿飲試喝最終主圖已發布並鎖定。 官網與發佈中心現在直接使用 GitHub 內的正式600×600 Web顯示版；1254×1254來源母本以原始SHA鎖定身份，不重新設計、不進入重生成、不重複排程。同一主圖90天內不再使用，除非再次人工審核。
其他試喝變體維持活動冷卻管理。為避免短期重複同一試喝活動，重複變體不自動排程、不自動發布；需要再次使用時仍需人工重新審核。
每篇提供三種ChatGPT重生成。「圖不符合｜ChatGPT生成」只重做圖片候選；「文案不符合｜ChatGPT重生成」只重寫文案；「全部重新生成」會重新建立文案與完整圖片需求。重生成需求會帶入六項正式產品、正式成分／使用資料、products-v3正式原圖、產品尺寸比例與網站同款小老闆規則；所有結果仍先回待審核。
固定排程：星期二 19:30、星期六 09:30。天氣、颱風、寒流、高溫、空氣品質等即時型貼文發布前需再確認當日資訊，不預先自動發布。臨時活動完成 ERP 正式審核後可使用真正的「立即發布」，不受固定時段限制。
