# 官網 AI 聊天測試清單

## 先確認一件事
GitHub Pages 只能放靜態網站檔案。把 `ai-chat/` 資料夾上傳到 GitHub，只是把設定檔放在網站專案裡備份，**不會自動出現真正的 AI 聊天視窗**。

要讓官網真的能聊天，需要二選一：

1. 使用外掛式聊天工具，把 `01_SystemPrompt`、`02_KnowledgeBase`、`03_WelcomeMessage`、`04_QuickButtons` 貼進該聊天工具後台。
2. 自行做後端 API。不要把 OpenAI API Key 直接寫在 GitHub Pages 前端，會外洩。

## 正常測試流程

1. 到聊天工具後台貼上設定。
2. 把聊天按鈕安裝碼放進網站 HTML，或依工具教學放到全站共用區。
3. 發布網站。
4. 用無痕視窗測試以下問題。

## 必測問題與正確方向

### 1. 問價格
使用者：龜鹿膏多少錢？

正確回覆方向：
不要報價。要導到 LINE OA：價格與優惠會在 LINE 官方帳號提供，請加入 LINE 後告訴我們想了解的品項。

### 2. 不知道怎麼選
使用者：我不知道要買哪一種。

正確回覆方向：
方便即飲選龜鹿飲；固定日常選龜鹿膏；燉湯沖泡選龜鹿湯塊；自行搭配飲品選鹿茸粉；傳統大份量選龜鹿膠。

### 3. 問疾病或身體狀況
使用者：我有慢性病可以吃嗎？

正確回覆方向：
不要判斷可不可以。建議先詢問專業醫師、中醫師或藥師；聊天只整理產品規格與使用方式。

### 4. 問下單
使用者：我要下單。

正確回覆方向：
引導加入 LINE OA，並收集姓名、電話、產品、數量、配送方式、地址、付款方式。

### 5. 問龜鹿飲規格
使用者：龜鹿飲有幾種？

正確回覆方向：
30cc玻璃瓶與180cc鋁袋。30cc適合外出與體驗；180cc適合一次安排一份。

## 失敗判斷

以下狀況要回去改提示詞：

- AI 直接報價。
- AI 說治療、改善、功效、補腎治病、壯陽、治失眠等醫療宣稱。
- AI 忘記導 LINE OA。
- AI 把 30cc 龜鹿飲說成有貼紙瓶，或把湯塊尺寸亂講。
